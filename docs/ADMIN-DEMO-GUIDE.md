## ✨ 核心改进

### 问题
之前版本的管理后台**必须连接Supabase数据库**才能登录，不适合演示和面试展示。

### 解决方案
新增**演示模式**，采用**本地验证 + Mock数据**，完全脱离数据库：

```
演示模式登录流程:
用户输入账号密码 
  → 前端本地验证（demo/Demo@123456）
  → 验证成功
  → 加载Mock数据
  → 展示后台功能
✅ 零网络请求，零数据库依赖
```

## 🔧 技术实现

### 核心代码逻辑

```javascript
// 1. 检查演示模式
const urlParams = new URLSearchParams(window.location.search);
isDemoMode = urlParams.get('demo') === 'true' || localStorage.getItem('admin_demo_mode') === 'true';

// 2. 本地验证登录
if (isDemoMode) {
    if (username === 'demo' && password === 'Demo@123456') {
        // 登录成功，加载Mock数据
        products = DEMO_PRODUCTS;
        orders = DEMO_ORDERS;
        // ...
    }
}

// 3. 数据加载跳过数据库
async function loadProducts() {
    if (isDemoMode) {
        products = DEMO_PRODUCTS; // 直接使用Mock数据
        renderProducts();
        return; // 不发送网络请求
    }
    // 正式模式：从数据库加载
    const supabase = window.supabaseClient.getClient();
    // ...
}
```

### 数据流对比

**演示模式**:
```
用户操作 → 前端Mock数据 → 渲染页面
         (无网络请求)
```

**正式模式**:
```
用户操作 → Edge Functions → Supabase数据库 → 返回数据 → 渲染页面
         (完整后端流程)
```

## ❓ 常见问题

### Q1: 演示模式的数据会保存到数据库吗？

**不会**。演示模式完全在浏览器本地运行，不发送任何网络请求。所有数据刷新后会重置。

### Q2: 可以在演示模式下添加/编辑数据吗？

**目前仅支持查看**。演示模式的数据是只读的，编辑功能会提示"演示模式不支持此操作"。

### Q3: 如何从演示模式切换到正式模式？

**三种方法**:

1. **点击徽章**: 右上角"演示模式"徽章 → 确认切换
2. **清除参数**: 访问不带 `?demo=true` 的URL
3. **清除存储**: 
   ```javascript
   localStorage.removeItem('admin_demo_mode');
   location.reload();
   ```

### Q4: 演示模式可以用于生产环境吗？

**不可以**。演示模式仅用于展示和面试，生产环境必须使用正式模式+数据库。

### Q5: 如何修改演示账号？

编辑 `web/admin/index.html` 文件中的 `DEMO_ADMIN` 对象：

```javascript
const DEMO_ADMIN = {
    username: 'your-username',
    password: 'your-password',
    // ...
};
```

### Q6: 如何修改Mock数据？

编辑 `web/admin/index.html` 文件中的以下数组：

- `DEMO_PRODUCTS` - 商品数据
- `DEMO_ORDERS` - 订单数据
- `DEMO_CARDS` - 卡密数据
- `DEMO_CATEGORIES` - 分类数据
- `DEMO_PAYMENTS` - 支付配置
