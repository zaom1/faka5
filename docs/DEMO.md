## 什么是演示模式

演示模式是本项目专为**简历展示**和**快速体验**设计的功能特点：

✅ **无需数据库** - 不需要配置 Supabase 或任何数据库  
✅ **即开即用** - 本地一行命令启动，在线访问添加参数即可  
✅ **完整流程** - 支持浏览商品、下单、支付、查看卡密的完整流程  
✅ **数据隔离** - 演示数据使用浏览器 localStorage，不影响真实环境  
✅ **HR友好** - 面试官/HR 可以零配置体验所有核心功能

## 快速启动

### 方式一：本地启动（推荐）

```bash
# 克隆项目
git clone https://github.com/yourusername/faka3.git
cd faka3

# 启动演示站
npm run demo

# 访问
# 前台: http://localhost:3000/index.html?demo=true
# 后台: http://localhost:3000/admin/index.html?demo=true
```

### 方式二：双击启动（Windows）

```
直接双击: scripts/deploy.bat
```

### 方式三：部署后在线访问

部署到 Netlify 后，访问：

```
https://your-site.netlify.app/?demo=true
```

## 完整购买流程

以下是在演示模式下体验完整购买流程的步骤：

### Step 1: 浏览商品

```
访问: http://localhost:3000/index.html?demo=true
```

- 查看首页商品列表
- 点击左侧分类筛选商品
- 使用搜索框搜索商品

### Step 2: 选择商品并购买

1. 点击任意商品的"购买"按钮
2. 弹出购买表单
3. 填写联系方式（QQ或邮箱，可填任意测试值）
4. 选择数量
5. 选择支付方式（USDT/信用卡/PayPal）
6. 点击"确认支付"

### Step 3: 查看订单

- 系统自动生成订单号
- 跳转到支付页面

### Step 4: 模拟支付

```
访问: http://localhost:3000/payment.html?order=DEMOxxxxxxxxx&demo=true
```

1. 查看订单详情
2. 看到加密货币地址
3. 点击 **"模拟支付成功"** 按钮
4. 页面更新为"支付成功"
5. 显示卡密信息

### Step 5: 查看卡密

支付成功后，页面显示：

```

账号: vip123@demo.com
```

## 常见问题

### Q1: 演示模式和正式模式有什么区别？

| 对比项 | 演示模式 | 正式模式 |
|--------|----------|----------|
| 数据来源 | 前端 Mock 数据 | Supabase 数据库 |
| 订单存储 | localStorage | 数据库 orders 表 |
| 支付流程 | 模拟支付 | 真实支付回调 |
| 管理后台 | 前端验证 | JWT Token 鉴权 |
| 数据持久化 | 刷新页面丢失 | 持久化存储 |

### Q2: 如何从演示模式切换到正式模式？

**方法一：** 访问不带 `?demo=true` 参数的URL

```
http://localhost:3000/index.html  # 正式模式
http://localhost:3000/index.html?demo=true  # 演示模式
```

**方法二：** 点击页面右下角"演示模式"按钮，确认切换

**方法三：** 清除 localStorage

```javascript
localStorage.removeItem('demo_mode');
location.reload();
```

### Q3: 演示模式可以用于面试展示吗？

**完全可以！** 演示模式就是为面试/简历展示设计的：

✅ 面试官可以零配置体验  
✅ 完整展示核心功能  
✅ 无需准备测试数据  
✅ 避免泄露真实数据  

### Q4: 如何将演示站部署到网上给HR看？

**推荐方案：**

1. **部署到 Netlify（免费）**
   ```bash
   npm run deploy
   ```

2. **分享演示链接**
   ```
   https://your-site.netlify.app/?demo=true
   ```

3. **在简历中写明演示地址**
   ```
   在线演示: https://your-site.netlify.app/?demo=true
   ```

### Q5: 演示模式的数据在哪里定义的？

数据定义在 `web/index.html` 文件中：

```javascript
const DEMO_PRODUCTS = [ ... ];  // 商品数据
const DEMO_CATEGORIES = [ ... ];  // 分类数据
```

如需修改演示数据，编辑这两个数组即可。

### Q6: 演示模式支持多人同时访问吗？

**不支持。** 演示模式是单用户本地体验的。

如需多人访问，需要：
1. 部署到 Netlify
2. 配置 Supabase 数据库
3. 切换到正式模式
